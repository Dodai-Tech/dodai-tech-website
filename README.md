# Dodai Tech website

Static site for `dodaitech.dev`, hosted on Cloudflare (Workers static assets, project `dodaitech`).
The pages are generated by `gen/` (Rust, uses `dodai-topcoat`) and **committed**, as is the
showcase wasm, so deploying is only an upload.

| Task | Command |
|---|---|
| Regenerate pages and CSS | `just gen` |
| Rebuild the browser showcase (needs a `dodai-ui` checkout) | `just showcase ~/Projects/dodai-ui` |
| Preview | `just serve` then http://127.0.0.1:8765 |
| Tests and dry-run deploy | `just check` |
| Deploy | `just deploy` |

## Deploying from another machine

Install Node and [Nushell](https://www.nushell.sh), then set `CLOUDFLARE_API_TOKEN` (permission
*Workers Scripts: Edit*) and `CLOUDFLARE_ACCOUNT_ID` and run `just deploy`.

## Deploying from CI

`.github/workflows/deploy.yml` deploys on every push to `main` (and by hand from the Actions tab).
Add the two values as repository secrets. CI never builds the site: `gen/` and the showcase need the
private `dodai-ui`, so regenerate locally and commit the output.
